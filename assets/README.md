# 78QuadLink visual identity

Original vector icon: `quadlink78.svg`, designed for this project.
The 78 monogram sits above a four-legged robot; the shared cyan line represents
one state bus and four amber feet represent the quadruped endpoints.

- `quadlink78.png`: 512 × 512 transparent-corner preview.
- `quadlink78.ico`: 16/32/48/64/128/256 px Windows/icon bundle.
- `quadlink78.svg`: editable source, no font dependency.

Regenerate PNG/ICO with `python3 scripts/render_icon.py` (PyQt5 + Pillow).
Rendering tools are not required to deploy or run the simulator.
