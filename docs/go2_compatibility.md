# Go2 兼容性：v0.5 初测与 v0.5.1 修复

当前适配范围限宇树系。**Go2 已在 v0.5.1 修复并通过验证，见 [原因、参数与测试报告](go2_tuning_v051.md)。**

以下保留 v0.5 初测失败记录，解释为什么旧版没有把 Go2 列入兼容名单。

测试使用 Unitree 官方 `unitree_ros` 提交 `ccfc6fd8430a17ba3dacef9a1e2faf64ff3b0aee` 的真实 Go2 模型，而非改名 Go1。模型来源/逐文件 SHA-256 见集成仓库 `models/unitree_go2/SOURCE.json`。

Go 准备器支持识别 Go2 的资源路径和 `imu` 链接别名，保留 60 个惯量/碰撞块、41 个关节定义。关节顺序仍映射固定十二关节；URDF 中髋/大腿力矩 23.7 N·m、小腿 45.43 N·m，不能照搬 A1 限位。专用实验控制器采用 Go2 的 0.0955 m 横向腿长、0.213 m 大腿/小腿长度和 16.087 kg 模型总质量。

控制器仍是现有框架的实验适配，并非宇树官方 Go2 步态控制器。平衡模型惯量使用 URDF 本体对角近似，步态增益沿用 A1，尚未完成 Go2 调参和动力学辨识。共享板/帧格式没有为 Go2 加入额外热路径转换。

首次共享电机 + IMU 运动检查失败：进入站立后姿态/高度不达标准，切换小跑触发姿态保护并倒下。十二路原路径也复现失稳：共享/十二路在运动前高度分别约 0.194/0.213 m，运动后约 0.072/0.076 m，均低于验收阈值。两条路径都失败，表明现有控制适配尚未过关，不能仅归因于共享内存。原始姿态摘要见 [go2_measurements.json](go2_measurements.json)。

没有把它算作有效性能样本，没有以“CPU 更低”掩盖功能失败。

v0.5 开发测试曾需 `SIM78_EXPERIMENTAL_GO2=1`；v0.5.1 验证通过后改为直接 `quadlink78 go2`。集成仓库 `tools/quadlink78/go2_check.sh` 按运动检查→两轮基线/共享对照顺序执行，运动不通过立即退出。

v0.5 当时设定的验证门槛（现已完成，结果见 v0.5.1 报告）：先使真实模型在原十二路控制和共享路径下均通过站立/小跑，核对同时间戳 IMU/TF、关节状态/命令与错误计数，再在同模型/传感器/RTF 条件下复测性能。v0.5 的失败运行不用于性能收益声明。
